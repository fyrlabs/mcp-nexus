mcp-nexus

4 tools·1 resource

From the serverMCP Nexus routes to many downstream MCP servers behind one endpoint. Workflow: search_capabilities to discover, describe_capabilities to inspect exact input schemas, execute_capability to run. Do not guess argument shapes: always describe a capability before executing it.

Install

Add this server to your MCP client of choice.

Terminal — project scope by default (-s user for global)
claude mcp add mcp-nexus -- npx -y @fyrlabs/mcp-nexus

Tools(4)

Describe capabilitiesdescribe_capabilities

Return the full metadata and input schemas for the given capability IDs.

Parameters

ParameterTypeDescription
capabilityIds required array<string> Capability IDs returned by search_capabilities

Example call

{
  "name": "describe_capabilities",
  "arguments": {
    "capabilityIds": [
      "<item>"
    ]
  }
}

Execute capabilityexecute_capability

Execute a downstream MCP capability by ID. The underlying server is started on demand and the arguments are forwarded verbatim.

Parameters

ParameterTypeDescription
capabilityId required string Capability ID to execute
arguments object Arguments matching the tool's input schema (see describe_capabilities)

Example call

{
  "name": "execute_capability",
  "arguments": {
    "capabilityId": "<capabilityId>"
  }
}

Search capabilitiessearch_capabilities

Search every indexed downstream MCP capability by natural language, keywords, tags, server id, or capability id. Returns lightweight metadata only.

Parameters

ParameterTypeDescription
query required string Natural language or keyword query describing the capability you need
limit integer Maximum number of results to return

Example call

{
  "name": "search_capabilities",
  "arguments": {
    "query": "<query>"
  }
}

Search serverssearch_servers

Rank configured downstream MCP servers against a domain-level query. Useful before drilling into capability search.

Parameters

ParameterTypeDescription
query required string Domain-level query such as 'project management'

Example call

{
  "name": "search_servers",
  "arguments": {
    "query": "<query>"
  }
}
